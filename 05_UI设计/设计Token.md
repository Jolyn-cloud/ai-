> **关联页面**：[闪卡首页.html](闪卡首页.html)

## 1. 颜色

### 主色
| Token | 值 | 用途 |
|---|---|---|
| `--primary` | `#5B72F5` | 全局主色：章节进度%、图标、标题装饰条 |
| `--primary-dark` | `#4358D7` | 主色按压态/深色层次 |
| `--primary-light` | `#EEF1FF` | 主色浅背景：章节图标容器 |

### 页面背景
| Token | 值 | 用途 |
|---|---|---|
| `--bg-bottom` | `#F8F9FC` | 页面底部兜底色 |

**`.page` 背景实现**：
使用 PM 提供的淡紫梦幻背景图为全屏背景，保持小程序视觉基调统一：
```css
.page {
  background: url('bg-flashcard-home.png') center top / cover no-repeat;
  background-color: #F8F9FC;
}
```

**`.bottom-mask` 下半遮罩实现**（保留顶部氛围图，下方渐变为干净白色，保证长列表可读）：
```css
background: linear-gradient(180deg,
  rgba(248,249,252,0) 0%,
  rgba(248,249,252,0.55) 18%,
  rgba(248,249,252,0.92) 44%,
  #F8F9FC 100%);
/* 定位：top: 320~380px; bottom: 0; */
```

| `--text-tertiary` | `#98A0B2` | 辅助文字：二级章节的已记住总数 |

### 语义色

## 3. 组件渐变

### 背诵计划卡（青蓝渐变）
```css
background: linear-gradient(135deg, #5572F6 0%, #6178F4 50%, #596CE8 100%);
box-shadow: 0 14px 32px rgba(76,99,221,0.25);
```

### 章节进度条（统一青蓝，不分级）
```css
background: linear-gradient(90deg, #5872F5, #6377F2);
/* 轨道底色 #E7EAF3，高度 3px */
```

### 主进度条（背诵卡内，白色半透明）
```css
/* 轨道 rgba(255,255,255,0.25)，填充 rgba(255,255,255,0.95)，高度 6px */
```

## 4. 卡片与阴影

### 章节卡片（白色半透明 + 毛玻璃）
```css
background: rgba(255,255,255,0.92);
backdrop-filter: blur(8px);
box-shadow: 0 5px 18px rgba(54,66,108,0.055);
border-radius: 17px;
```

### 用户头像
```css
background: linear-gradient(145deg, rgba(255,255,255,0.9), rgba(235,239,255,0.95));
border: 1px solid rgba(255,255,255,0.8);
box-shadow: 0 8px 24px rgba(75,91,160,0.08);
```

### 继续按钮
```css
background: rgba(255,255,255,0.98);
color: #536BE8;
box-shadow: 0 4px 10px rgba(48,65,150,0.06);
```

## 6. 图标
- **风格**：Lucide 线性图标，`stroke-width: 1.8`，圆角端点
- **章节图标容器**：44×44，圆角 13px，底色 `--primary-light`，图标描边 `--primary`
- **背诵卡数据图标**：48×48，圆角 14px，底色 `rgba(255,255,255,0.18)`，图标描边白色
