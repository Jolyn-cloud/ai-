## 四、登录/画像/VIP 流程挂法

```
闪屏(view-splash) → 2.5s → 学习(view-home)
  → 第一次点功能(发问/补资料) → VIP福利弹窗(可关) [新用户专享，未登录可提示不强制]
      ├─ 稍后再说 → 继续原功能
      └─ 立即领取 → VIP页面 → 未登录则在 VIP页内登录 → 登录成功 → 领取成功
  → 画像弹窗：登录后 首次使用 AI对话时 前置问答(专业+年级)
  → 已领/已登录 → 不再弹窗，VIP 作为「我的」常驻入口
```

- **登录弹窗**（带隐私协议勾选）独立 `loginMask`，任意关键功能触发
- **画像弹窗** `profileMask`，挂 AI 对话首次使用
- **VIP福利弹窗** `vipMask` 新加，新用户第一次点功能触发，可关
- **VIP页面** `view-vip` 新加独立视图：未登录则在页内登录 → 领成功

## 六、风险与兜底

| 风险 | 兜底 |
|---|---|
| CSS 合并后选择器冲突 | 两文件 token 一致（#5B72F5等），类名前缀隔离（他用 app-xxxx） |
| id 冲突（两文件都有 view-home/statusTime） | 登录画像的 view-home → 改名 view-ai；statusTime 共用自动时钟 |
| `nav()` 与底部 tab 联动 | tab 点击调 nav()，nav() 更新底部 tab active 态 |
| 闪屏自动进入 vs 直接 tab | 首启动闪屏，闪屏结束后底部 tab 高亮"学习" |
| 1800行闪卡JS搬入后作用域污染 | 共享函数去重 + 每步 CDP 全量回归 |
