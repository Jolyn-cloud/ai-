## 0. 页面职责

**单卡模式**：一张一张翻卡、左右滑动判定「已记住 / 未记住」的刷题页。
用户：学生。可操作。

---

## 1. 队列来源与过滤（区块① 顶部进度）

### 数据逻辑
- **进入方式决定队列来源（两套队列独立）**：
  - **无 URL 参数**（首页「开始学习/继续背诵」进入）→ `loadState()` 读取**当日队列**（`localStorage['flashCardState_v2']`，按天隔离），进度跨模式共享（和列表模式同一份）。
  - **带 URL 参数**（`?chapter= ` `?sub= ` `?topic= ` `?point=`，从首页章节/章节统计页跳入）→ 用 `buildFullQueue()` 构建**全卡池队列**（全部 CARDS，不抽样、不按配额），保证任意考点都能刷到全部题目。`marked` 复用当日已标记（同 key 同步），baseState 仍保存当日。
- **顶部进度**（`已刷 N / 总量`，progress-info）：
  - `N` = `state.marked` 中已标记的 key 数（已记住 + 未记住）；
  - `总量` = `state.quota` = 队列长度（当日队列 = 每日配额；过滤队列 = 匹配卡片数）。
- **标记一律写回 baseState**，过滤视图（`state`）即时刷新（`filterState(baseState, filter)`）。

### 字段规则
- 进度条：`width = min(done/total*100, 100)%`，超100%截断。
- 卡片标签：`一级章节 - 二级章节`（左对齐，两行：题型标签 + 类型标签）。
- 输出卡片标签区含「顽固卡」「今日重现」角标：仅当 `forgotCount≥3`（顽固）/ 为今日未记住副本（round≥2）时渲染。

### 去向
- 进度写回当日状态 → 首页「总进度」= 全章节已记住/卡池总数。无过滤时全部章节混合随队列顺序；

## 2. 翻卡（区块② 卡片正面/背面）

### 数据逻辑
- **正面**：`clozeHtml(question)` → 填空题干（`____` 渲染为视觉空位）；
- **背面**：`clozeHtml(question, answer)` → 空位填入答案高亮 + 答案 + 解析（`card-answer` / `card-analysis`）。
- 卡片字段：`chapter/sub/topic/point/question/answer/analysis/forgotCount`。

### 操作
- 轻触卡片 → `flipCard()` 翻转（正面↔背面）。**翻转不计入答题记录、不改任何状态**。
- 翻卡动画期间（`isAnimating=true`，飞出/飞入 400ms）忽略所有点击/滑动。

### 强约束（与规则 §3.2 一致）
- **不翻卡不能滑动判定**（防不看答案乱滑数据失真）：
  - 正面（未翻转）拖拽 → 不进入"标记判定"模式，而是**导航模式**：左滑=上一张（撤销方向）、右滑=下一张（跳过），**不标记**；
  - 只有背面（已翻转）拖拽 → 进入标记判定：右滑已记住 / 左滑未记住。
- 边界阻尼：正面左滑但 `historyStack` 为空 / 右滑但后面无待答卡 → 位移×0.25 回弹 + 摇晃提示（`shakeWarn`）。

### 去向
- 翻卡状态（`isFlipped`）在 `goNext/goPrev/commitCard` 切换卡片时**重置为未翻转**。

## 3. 滑动判定（区块③ 卡片拖拽）

### 数据逻辑（阈值口径，代码实证）
| 场景 | 判定点 | 提交方式 |
|---|---|---|
| 翻卡后（背面）拖动 | `|dx| ≥ 170px`（EDGE_THRESHOLD，卡片区约50%） | **拖到侧边立即判定**（无需松手，`autoCommitted`） |
| 翻卡后（背面）拖动 | `|dx| ≥ 80px`（SWIPE_THRESHOLD） | **松手时判定**（`handleDragEnd`） |
| 翻卡后（背面）拖动 | `|dx| < 80px` | 回弹归位（不标记） |
| 正面（未翻转）拖拽 | 左滑 `dx<-80` → 上一张；右滑 `dx>80` → 下一张 | 松手判定，**不标记** |
| 正面拖拽 | 未达 `|dx|>8 且 |dx| > |dy|×1.2`（水平意图） | 不进入导航拖拽，不阻止默认（可滚动） |

### 操作
- 判定 `dx>0`（右滑）→ `commitCard('remembered')`；`dx<0`（左滑）→ `commitCard('forgot')`。
- 滑动过程遮罩反馈：右侧绿色「已记住」/ 左侧红色「未记住」，`opacity = min(|dx|/80, 1)×0.9`。

### 提交后的动作链
1. **防重复标记**：`state.marked[key]` 已存在 → 直接 return（不重复提交）；
2. 记录 `historyStack`（供「上一张」撤销）：`{key, result, prevForgotCount}`；
3. 调 `markCard(...)`：写 `marked[key]=result`；**未记住** → 该卡累计 `forgotCount+1`（同 id 副本同步）＋ **塞回队尾当天重现**（`round+1` 副本，key 变为 `id#round+1`）；
4. `saveState(baseState)` + `refreshFilter()`（副本进入过滤视图）；
5. 400ms 飞出动画后：若 `done ≥ total` → 完成结算页；否则渲染下一张未标记卡（`findNextPending()`）。

### 底部统计条（实时）
- 已记住 N / 未记住 N / 顽固 N，每次标记即时刷新：
  - `已记住` = marked 中 `remembered` 数（含过滤范围）；
  - `未记住` = marked 中 `forgot` 数；
  - `顽固` = 累计 `forgotCount≥3` 的卡（**id 去重**计数）。

### 去向
- 已记住 → 进入艾宾浩斯长间隔队列（+1/+2/+4/+7/+15/+30天，见功能规则 §2）；未记住 → 短间隔（当天末重现 + 明天必现）；顽固卡每天必现。

## 4. 上一张 / 下一张（区块④ 导航）

### 数据逻辑
- **上一张（撤销）**：`historyStack` 非空才可点（底部「上一张」按钮 `disabled` 跟随）。按压后：
  1. `pop` 最近一次标记，`delete baseState.marked[key]`；
  2. 若是「未记住」，还需撤销 markCard 副作用：移除 `round` 最大的副本（`round>1`）、把该 id 所有 `forgotCount` 恢复为撤销前值；
  3. `saveState` + `refreshFilter`，重置 `historyRecorded=false`、清结果去重标记；
  4. 渲染该卡（未标记状态）可重新作答。
- **下一张（跳过）**：`findNextPendingAfter(currentCard)` —— 当前卡之后第一张未标记的卡；无则禁用。被跳过的卡**保留在待答队列中**，之后仍会出现。
- 进度不因跳过改变（`marked` 没写）。

### 强约束
- 导航只发生在**正面（未翻转）**拖拽，或点底部「上一张/下一张」按钮；
- 边界（已无上一张 / 无下一张）：回弹 + `shakeWarn` 摇晃提示，不切卡。

### 去向
- 撤销后若全部重新标记完 → 重新可进完成结算页（`historyRecorded` 已重置）。

## 5. 完成结算页（区块⑤ 学习成果）

### 数据逻辑
| 元素 | 口径（代码实证） |
|---|---|
| Hero 文案 | `accuracy≥80` → "不错哦！🎉"；`≥60` → "继续加油！💪"；否则"再加把劲！📚" |
| 环形图 | 圆心 `accuracy% = round(remembered/done×100)`，`strokeDashoffset` 动画从 251.33 → `251.33×(1-accuracy/100)` |
| 核心指标 | 总卡数 `total` / 已记住 `remembered` / 未记住 `forgot`（calcStats 口径） |
| 薄弱 TOP5 | `getWeakPoints(state,5)`：按 forgot 降序 → 同次数按 total 降序；无则"本轮全部掌握，暂无薄弱点 🎉" |
| 章节掌握度分布 | 按 chapter 聚合 `remembered/forgot/total`，柱条 = okWidth% / badWidth% |
| 效率分析 | 用时 `formatDuration(getSessionElapsed())`（M:SS）；速度 `round(elapsed/done)s/张`；较上次 `(lastH.speedSec - speedSec)/lastH.speedSec` → ↑/↓% 或"持平"；无上次 → "首次" |
| 底部按钮 | 有 `chapter` 过滤时多一个「下一章」（定位下个一级章节）；始终有「返回首页」「再背一轮」 |

### 操作（完成判定）
- 触发时机：`commitCard` 后 `stats.done ≥ stats.total`（当日队列 = 配额全刷完；过滤=范围内全刷完）。**未记住副本仍在队列中不再继续出现**（直接算完成）。
- **历史记录去重**：同一天同已刷张数只记一次（`localStorage['flashCardResultRecorded_v1']` 存 `日期#done`），刷新/重进不重复写入；`recordHistory` 存进 `flashCardHistory_v1`（保留 30 条）。
- 「再背一轮」：`restart()` 生成**全新当天状态**（跨天 forgotCount 仍保留在卡片上），清计时，重新进入。

### 去向
- 历史 `flashCardHistory_v1` 供下一页「较上次」对比；首页进度同源。

## 6. 进入/退出与会话

### 数据逻辑
- 进入时 `getSessionStart()` 无值 → `startSession()` 记 `flashCardSessionStart_v1`（毫秒时间戳），完成结算时 `clearSessionStart()`；
- 不同天 `loadState()` 检测 `date !== todayStr()` → 自动新建当天状态（按天隔离）。

### 强约束
- 中途退出再进入：队列保持当天状态（不重新打乱）；刷新后从上次进度继续。
